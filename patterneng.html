✨ 核心规律：英文词汇完全服从粤语句法结构 ✨
🕒

动词与体貌词

保留英文动词原形，舍弃时态变化（-ed, -ing），直接加上粤语体貌词（如：紧、咗、完、定、过、住）。

  • 我 print 紧
    我正在打印 (进行体)
  • 已经 send 咗
    已经发送了 (完成体)
  • 啱啱 check 完
    刚刚检查完毕 (完结体)
  • 我 book 定先
    我先预订好 (预期体)
  • 你 try 过未？
    你尝试过了吗？ (经验体)
  • 个网页 load 紧
    网页正在载入 (进行体)
  • 佢 cancel 咗个会
    他取消了会议 (完成体)
  • 等我 update 完
    等我更新完毕 (完结体)
  • 记得 save 咗先
    记得先存档 (完成体)
  • 我未 claim 过
    我还没报销过 (经验体)
📍 加上“住” (持续体/状态体)

表示动作的持续、状态的保持，或暂时维持某个动作。

  • 大家 hold 住先
    大家先撑住 / 暂停一下
  • 你要 keep 住做
    你要保持着继续做
  • 帮我 mark 住个期
    帮我先把日期标记保留起来
  • 个 file save 住先
    文件先存档留着
  • 架车 block 住条路
    车子挡住了路
  • 个 screen lock 住咗
    屏幕被锁住了
  • 条片 pause 住先
    影片先暂停着
  • 间房 book 住先啦
    房间先预订保留着吧
  • 个掣 hide 住咗
    按钮被隐藏起来了
  • 我会 follow 住单 case
    我会持续跟进这个案子

正反问句 (A-唔-A) - 20 个精选例子

套用粤语“动词+唔+动词”的问句结构。多音节英文字通常只重复第一个音节。

  • 你 sure 唔 sure？
    你确定吗？
  • 你 con 唔 confirm？
    你确认吗？
  • 呢个 make 唔 make sense？
    这个合理吗？
  • 你 keep 唔 keep？
    你要保留吗？
  • 佢 pass 唔 pass？
    他及格了吗？
  • 你 join 唔 join？
    你要参加吗？
  • 个 app work 唔 work？
    这个应用程序能运作吗？
  • 你 pre 唔 prefer？
    你偏好这个吗？
  • 你 a 唔 agree？
    你同意吗？
  • 佢 re 唔 reply？
    他有回复吗？
  • 你 mind 唔 mind？
    你介意吗？
  • 呢个 match 唔 match？
    这个相配吗？
  • 你 care 唔 care？
    你在乎吗？
  • 呢条裙 fit 唔 fit？
    这条裙子合身吗？
  • 你 feel 唔 feel 到？
    你感觉得到吗？
  • 佢 sup 唔 support？
    他支持吗？
  • 你 en 唔 enjoy？
    你享受吗？
  • 佢 quali 唔 quali？
    他够资格吗？(qualify)
  • 个系统 run 唔 run 到？
    系统能运行吗？
  • 你 pay 唔 pay？
    你付钱吗？

名词与量词

遵守粤语“数字 + 量词 + 名词”的规则。通常会省略英文复数的 -s。

  • 一 个 file
    一个文件
  • 两 部 computer
    两部电脑
  • 三 个 project
    三个项目
  • 四 条 link
    四条链接
  • 五 个 case
    五个案例
  • 六 张 form
    六张表格
  • 七 个 offer
    七个录取通知
  • 八 堂 tutorial
    八堂导修课
  • 九 个 folder
    九个文件夹
  • 十 份 report
    十份报告
🔁

动词叠词

将英文动词重叠使用，用来表示短暂的动作，或者让语气变得委婉、轻松。

  • 等我 check check
    让我先检查一下
  • 不如 try try
    不如试试看这个方法
🔄

名词作动词用

将英文的专有名词、科技词汇或工具名称，直接当作粤语的及物动词来使用。

  • 转头 WhatsApp 我
    晚点用 WhatsApp 传讯息给我
  • 唔识就 Google 吓
    不懂的话就搜索一下吧
💬

句末语气助词

即使整句或半句是英文，句尾依然可以无缝接上粤语助词，补充情感态度。

  • That's fine 啦
    没关系啦 (带有妥协/安抚)
  • Very good 喎！
    很好耶！ (带有惊喜/赞赏)
🧩

短语动词单字化

将英文短语动词视为不可分割的单一动词，宾语放在整个短语之后。

  • 去机场 pick up 佢
    去机场接他 (不说 pick 佢 up)
  • 记得 back up 咗先
    记得先备份
🛡️

被动语态 (畀字句)

结合粤语的被动句结构：“畀 + 人/事物 + 英文动词 + 咗”。

  • 个 account 畀人 block 咗
    账号被人封锁了
  • 份 proposal 畀老板 reject 咗
    企划书被老板拒绝了
🤝

动宾结构混搭

跨语言的动词与宾语组合，常见“粤语动词＋英文名词”或“英文动词＋粤语名词”的无缝配搭。

📍 粤语动词 + 英文名词
  • 食 lunch
    吃午餐
  • 开 meeting
    开会
  • 睇 show
    看表演
  • 抄 notes
    抄笔记
  • 写 email
    写电子邮件
📍 英文动词 + 粤语名词
  • book 枱
    订位
  • keep 数
    记账
  • claim 钱
    报销款项
  • print 功课
    打印作业
  • send 信
    寄信
