⑩ 粤语夹杂英文
粤语夹杂英文 是一种非常普遍的语言现象，尤其在职场。表面上看似随意，但其实有着一定的语法规律。句子的核心文法结构仍然是「粤语」，英文字只是作为词汇被「镶嵌」到粤语的语法框架中。以下是粤语夹杂英文中最常见的语法规律。

1. 英文动词 + 粤语体貌词

在职场和日常交流中，粤语使用者经常将特定的英文动词（如: book, check, confirm, hold, keep, send, update）直接当作粤语动词使用，并在其后无缝接上粤语的体貌词（如: 紧、咗、定、过、返、住、晒）。

2. 粤语动词 + 英文名词

除了将英文动词粤语化，职场中更常见的是使用地道的粤语单音节动词，直接搭配英文职场名词。

  • 1. 交 report (提交报告)
    粤 今日做完系统年检，下个礼拜要 交 report 。
    普 今天完成了系统年检，下周要提交报告。
  • 2. 入 data (录入数据)
    粤 呢两日净系坐喺度 入 data，做到眼都花。
    普 这两天光是坐在这里录入数据，弄得眼都花了。
  • 3. 签 contract (签合同)
    粤 个客终于肯 签 contract 喇，今个月够数啦！
    普 客户终于肯签合同了，这个月业绩达标啦！
  • 4. 覆 message (回复信息)
    粤 我开紧会，转头先 覆 message。
    普 我正在开会，晚点再回复信息。
  • 5. 填 form (填写表格)
    粤 申请报销要先 填 form。
    普 申请报销要先填写表格。

3. 英文动词 + 粤语名词

在职场交流中，除了“粤语动词+英文名词”，同样常见的是直接使用英文动词搭配粤语名词。

  • 1. book 房 (预订会议室)
    粤 听日下昼开会，记得 book 房。
    普 明天下午开会，记紧预订会议室。
  • 2. claim 钱 (报销款项)
    粤 出差搭的士啲收据记得留低 claim 钱。
    普 出差打车的收据记得留下来报销。
  • 3. check 数 (核对账目/数据)
    粤 会计部月底要 check 数，大家交齐单未？
    普 财务部月底要核对账目，大家交齐票据了吗？
  • 4. set 场 (布置场地)
    粤 听日有发布会，今晚大家要留低 set 场。
    普 明天有发布会，今晚大家要留下来布置场地。
  • 5. update 资料 (更新资料)
    粤 客户转咗电话，记得帮佢 update 资料。
    普 客户换了电话，记得帮他更新资料。

4. 程度副词 + 形容词

使用粤语的程度副词（如“好”、“超”、“鬼死咁”）直接修饰英文形容词。

  • 1. 好 nice
    粤 佢个人 好 nice。
    普 他这个人很友善。
  • 4. 好 cute
    粤 只猫 好 cute。
    普 这只猫很可爱。
  • 6. 好 pro (professional)
    粤 佢做嘢 好 pro。
    普 他做事很专业。
  • 8. 好 urgent
    粤 件事 好 urgent。
    普 这件事很紧急。
  • 9. 好 relax
    粤 感觉 好 relax。
    普 感觉很放松。
