⑩ 粤语夹杂英文
粤语夹杂英文 非常普遍，尤其在职场。句子的核心文法结构仍然是「粤语」，英文字只是作为词汇被「镶嵌」到粤语的语法框架中。

1. 英文动词 + 粤语体貌词

在职场交流中，经常将英文动词直接当作粤语动词使用，并在其后接上粤语的体貌词（如: 紧、咗、晒、过、住）。

  • update 紧
    粤 个系统 update 紧，暂时用唔到。
    普 那个系统正在更新中，暂时用不了。
  • book 咗
    粤 我 book 咗 下个礼拜嘅机票。
    普 我预订了下个星期的机票。
  • confirm 晒
    粤 所有行程都 confirm 晒，听日准时出发。
    普 所有行程都全部确认好了，明天准时出发。
  • check 过
    粤 呢条数我寻日 check 过，应该冇错。
    普 这笔账我昨天核对过，应该没错。
  • keep 住
    粤 大家 keep 住 呢个进度，下个礼拜就搞掂。
    普 大家保持住这个进度，下个星期就搞定了。

2. 粤语动词 + 英文名词

除了将英文动词粤语化，职场中更常见的是使用地道的粤语单音节动词，直接搭配英文职场名词。

  • 交 report
    粤 今日做完系统年检，下个礼拜要 交 report。
    普 今天完成了系统年检，下周要提交报告。
  • 入 data
    粤 呢两日净系坐喺度 入 data，做到眼都花。
    普 这两天光是坐在这里录入数据，弄得眼都花了。
  • 签 contract
    粤 个客终于肯 签 contract ，今个月够数啦！
    普 客户终于答应签合同，这个月业绩达标了！
  • 覆 message
    粤 我开紧会，转头先 覆 message。
    普 我正在开会，晚点再回复信息。
  • 填 form
    粤 申请报销要先 填 form。
    普 申请报销要先填写表格。

3. 英文动词 + 粤语名词

在职场交流中，除了“粤语动词+英文名词”，同样常见的是直接使用英文动词搭配粤语名词。

  • book 会议室
    粤 听日下昼开会，记得 book 会议室。
    普 明天下午开会，记紧预订会议室。
  • claim 钱
    粤 出差搭的士啲收据记得留低 claim 钱。
    普 出差打车的收据记得留下来报销。
  • check 数
    粤 会计部月底要 check 数，大家交齐单未？
    普 财务部月底要核对账目，大家交齐票据了吗？
  • set 场
    粤 听日有发布会，今晚大家要留低 set 场。
    普 明天有发布会，今晚大家要留下来布置场地。
  • update 资料
    粤 客户转咗电话，记得帮佢 update 资料。
    普 客户换了电话，记得帮他更新资料。

4. 程度副词 + 形容词

使用粤语的程度副词（如“好”、“超”、“鬼死咁”）直接修饰英文形容词。

  • 好 nice
    粤 佢个人 好 nice。
    普 他这个人很友善。
  • 好 cute
    粤 只猫 好 cute。
    普 这只猫很可爱。
  • 好 fit
    粤 我呢排日日跑步，状态 好 fit。
    普 我最近每天跑步，状态很好。
  • 好 urgent
    粤 件事 好 urgent。
    普 这件事很紧急。
  • 好 relax
    粤 感觉 好 relax。
    普 感觉很放松。
